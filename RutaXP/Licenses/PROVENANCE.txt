RutaXP leveling guide adaptation
===============================

EarlyQuestData.lua contains IDs selected by RutaXP for early pickup.
Forever quest facts: Efficient Games (https://efficient.games), CC BY 4.0
(https://creativecommons.org/licenses/by/4.0/), builds 1.60.1.70790 and 1.60.1.70840.
Original data: https://github.com/JIVESCORP/eg-link-output-wowf/tree/45f58b070b84501f8001bdcad43864aa929a6a4b/data/wowf
The Furlbrow errands were also checked against build 1.60.1.70862:
https://github.com/JIVESCORP/eg-link-output-wowf/tree/156f29c9af78b1586883e8eb94a13467eb89638c/data/wowf/1.60.1.70862
Quest types, objectives, timers and start scripts were cross-checked with
CMaNGOS Classic-DB, GPL-3.0:
https://github.com/cmangos/classic-db/tree/c33f90b8eeb3f8bacb53d5cbfee45075c80b416c
RutaXP filters the records and joins them to its guide routes.
Source hashes and selection rules are in tools/build_early_quest_offers.py.

Original guide routes: Polestar, by Fitz and contributors.
Spanish adaptation and translation: SendaFH / Forever Hispano.
Source: https://github.com/julen92/SendaFH
Branch: sendafh
Commit: 5d207e28e82e2c529143b21ace74fe88692f0067

RutaXP captures the 57 Leveling guides, applies SendaFH's Spanish
presentation catalogue and preserves all grouped goals, prerequisites,
conditions, quest/object/NPC/item IDs and coordinate frames.
RutaXP's import and build tools produce the editable Source/leveling.json
snapshot and the runtime Leveling.lua and MapFrames.lua from that snapshot.

Adapted guide text and original project code are GPL-3.0-only.
The compiler exception does not remove the GPL from copied guide text.
Read SendaFH-GPL-3.0.txt, SendaFH-LICENSE-EXCEPTION.md,
SendaFH-THIRD_PARTY.md and Polestar-Guide-Data.txt for original notices.

The upstream pack resolves factual quest/NPC/object/item records from
sources including pfQuest, Blizzard tables and QuestieDB. The notices
identify their provenance and licensing separately. No Questie code or
quest narrative text is imported by RutaXP's capture tool.

These are beta routes, not fully play-tested Forever guides. The 30-60
route includes Classic and known Forever quests while new content is
still being added. The Spanish catalogue also needs in-game review.

RutaXP 0.3.0 intermediate waypoints
--------------------------------
Source/waypoints.json records the exact source location and revision for
each included cave entrance, crossing and transport endpoint. Waypoints.lua
contains the runtime snapshot. Coordinates are taken from the same pinned
Polestar / SendaFH revision above; there is no invented terrain geometry.
The zone-crossing endpoints originate in Carbonite-Classic's
Data/classic/ZoneConnections.lua, commit
4d062800ae0c77c3f52ecf436b175bf06dcced4a, under GPL-3.0.
Transport endpoints come from the upstream generated Nav/TravelData.lua.
The existing SendaFH-THIRD_PARTY.md retains the original travel-data and
Carbonite notices. Missing source altitudes remain unknown.

The 0.7.5 guide links in AllianceTravel.lua and HordeTravel.lua follow the
same pinned Forever guide itineraries and NPC positions. The road, port,
zeppelin and train endpoints in TravelConnections.lua are extracted from
tools/lib/travel/crossings.json and addon/SendaFH/Nav/TravelData.lua by
tools/build_travel_connections.py. Flight masters are faction-specific;
each stop retains the coordinate frame of its source.

Later RutaXP releases include the walking router and navigation maps in
Pathing/, adapted from the pinned Polestar/SendaFH revision. That directory
retains the Shortest Path Forever and Polestar credits, GPL licence, source
revisions and file hashes in CREDITS.md, UPSTREAM.json, VENDORED.json and
PACK.json. See those notices for the exact code and data provenance.

The Media/ graphics are also retained from Polestar/SendaFH, under the
upstream notices in SendaFH-THIRD_PARTY.md. Antigravity's integration and
interface changes do not change the authorship of those original assets.

RutaXP 0.7.9 availability audit and reviewed chains
------------------------------------------------
EverythingQuests (Wheelbarrel00), MIT, commit
8e7aa971319226f984639d4dae06e864b50c4fb4:
https://github.com/wheelbarrel00/EverythingQuests
AllTheThings WoW Addon, MIT, commit
b50b6d8335d56a215bb3053811745f617532cc14:
https://github.com/ATTWoWAddon/AllTheThings
Only numeric facts and provenance are captured for this audit. Source file
hashes, line references, limits and cross-source disagreements are recorded
in Source/quest_requirements_evidence.json and quest_requirements_audit.json.

authored actions remain accounted for. Complete MIT notices accompany these

RutaXP 0.7.10 Darkshore and successor review
-----------------------------------------
QuestieDB commit 21be34023b72cf2ec3027cb9a61a8b72a1910857,
src/corrections/Forever/foreverQuestFixes.lua, and the public correction
https://github.com/Questie/Questie/issues/8040 corroborate the nine numeric
prerequisite IDs for Holy Diver (87760). No Questie code or narrative quest
text is imported. QuestieDB-NOTICE.md preserves the original licensing
notice; this reference must not be represented as MIT-licensed source.
Source/guide_revisions.json records the exact file hash and line references.

Three missing Wetlands quest chains are reconstructed from numeric NPC,
object, item, objective and coordinate facts in the same pinned SendaFH,
EverythingQuests and AllTheThings sources above. Source/successor_review.json
records the reviewed Alliance chapters and unresolved source discrepancies.

RutaXP 0.7.12 Human Rogue equipment
-----------------------------------
tools/review_human_rogue.py uses the SendaFH commit identified above.
addon/SendaFH_ItemDB/Forever.lua contains quest rewards and item data from
ForeverLevelingBiS v0.12.0-beta by Thunder (2026-10-13). The full upstream
notice is reproduced in ForeverLevelingBiS-MIT.txt. Items.lua provides
Blizzard Classic Era item facts when no Forever-specific record exists.
Missing reward lists use SendaFH_Codex, and item names use SendaFH_Names_esES.
In-game comparisons use the values available on that player's client.
Rogue one-handed axes and the two-dagger requirement for Mutilate:
https://worldofwarcraft.blizzard.com/es-es/news/24310968
The Westfall chest (2041) comes from quest 166 at the end of the Defias
chain. Quest links are in SendaFH_QuestDB/Quests.lua, item attributes in
SendaFH_ItemDB/Items.lua and reward options in SendaFH_ItemDB/Forever.lua.
